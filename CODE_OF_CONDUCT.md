# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep discussions focused on the work. Harassment, personal attacks and discriminatory language are not tolerated.

Report unacceptable behavior privately through [GitHub Security Advisories](https://github.com/Raggzinn/chainfolio/security/advisories/new) or by contacting the maintainer on GitHub. All reports are handled confidentially.
